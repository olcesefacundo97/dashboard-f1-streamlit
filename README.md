# 🏎️ Formula 1 Interactive Dashboard

Interactive data analytics dashboard built with **Python** and **Streamlit** to explore Formula 1 performance, circuits, rankings and predictive insights.

This project combines API/data consumption, exploratory analysis, visualization and storytelling to turn racing data into clear insights for users.

## Demo

[Open the Streamlit app](https://dashboard-f1-app-mw5qn2usae925pwjhrkumf.streamlit.app/)

## Project Value

The goal of this dashboard is not only to display Formula 1 data, but to create an analytical experience where users can:

- Compare drivers and teams.
- Explore performance patterns across circuits, countries and conditions.
- Understand consistency, ranking evolution and competitive gaps.
- Review visual insights through charts, maps and summaries.
- Test a simple predictive approach for final position estimation.

## Main Features

- Interactive circuit map.
- Driver and constructor rankings.
- Dynamic comparisons by weather, country and team.
- Final position prediction based on qualifying position, weather and constructor.
- Consistency and performance metrics.
- Radar charts, boxplots and correlation analysis.
- User feedback and automated analytical conclusions.

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib / Plotly
- API/data processing
- Data visualization
- Machine Learning basics

## Analytical Focus

This project was designed around a data storytelling flow:

1. Load and process Formula 1 data.
2. Transform raw data into analytical tables and metrics.
3. Build interactive visualizations for exploration.
4. Add business-style conclusions and performance insights.
5. Include a basic predictive component to estimate race outcomes.

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/olcesefacundo97/dashboard-f1-streamlit.git
cd dashboard-f1-streamlit
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the app

```bash
streamlit run app.py
```
